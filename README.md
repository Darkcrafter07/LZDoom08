## How to build LZDoom08

To build LZDoom, please see the [wiki](https://zdoom.org/wiki/) and see the "Programmer's Corner" on the bottom-right corner of the page to build for your platform.
To build LZDoom08 for Windows XP, use CMake or CMakeGUI 4.3.2, target MS Visual Studio 2022 (or 2019, 2017 but that's NOT confirmed), in toolset type without quoutes "v141_xp".
Enable "IknowTheUnknown" and "MadeForWindowsXP" checkboxes in the red/white fields before generating the project.
